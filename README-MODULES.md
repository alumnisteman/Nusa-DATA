# RESTART AI — PHK + Pensiunan + Work DNA + Real Data Engine

> **Operating System untuk Kehidupan Kerja Kedua.**
> Bukan sekadar job portal. RESTART AI mengubah pengalaman masa lalu menjadi economic assets.

---

## Prinsip Dasar

- **Tidak ada dummy production data.** Semua statistik eksternal memiliki sumber, periode, waktu pengambilan, lisensi/status akses, dan quality status.
- **AI tidak boleh menaikkan status** menjadi `HUMAN_VERIFIED` atau `OFFICIAL_PUBLIC`.
- **Reputasi dibangun dari bukti, bukan klaim.**
- **Pengalaman masa lalu adalah aset ekonomi**, bukan beban.

---

## Data Trust Levels

| Level | Keterangan |
|---|---|
| `SELF_DECLARED` | Dinyatakan sendiri oleh user |
| `AI_ASSISTED` | Dibantu AI untuk ekstraksi/strukturisasi |
| `EVIDENCE_ATTACHED` | Dilengkapi dokumen/bukti |
| `HUMAN_VERIFIED` | Diverifikasi oleh manusia |
| `OFFICIAL_PUBLIC` | Data resmi publik (BPS, Kemnaker, dll) |
| `LICENSED_PARTNER` | Data dari mitra berlisensi |

                |

**Sistem Trust Progression:**

Skill: "Project Management"
- SELF_DECLARED      (klaim sendiri)

Semakin kuat trust level, semakin tinggi nilai ekonomis skill tersebut.

## Data Sources

### BPS (Badan Pusat Statistik)
- Menyediakan WebAPI untuk integrasi data statistik agregat
- Perlu registrasi dan token akses
- Cakupan: angkatan kerja, pasar tenaga kerja, pekerjaan, pengangguran
- **Gunakan WebAPI resmi setelah kredensial diperoleh**

### BKN (Badan Kepegawaian Negara)
- SIASN: sistem terintegrasi data ASN nasional
- Integrasi layanan pensiun dengan ASABRI
- **Jangan scraping atau mengambil data individual**
- Integrasi individual hanya melalui jalur resmi/otorisasi

### Kemnaker
- Data pasar kerja, lowongan, pelatihan
- Akses melalui portal resmi

## Catatan Penting

1. **Schema adalah foundation, bukan berarti langsung migration ke production.**
   Selalu: staging -> test -> deploy.

2. **AI tidak boleh mengarang data.** Setiap angka harus punya sumber.

3. **Modul TypeScript di apps/api/src/modules/** adalah service layer —
   perlu dihubungkan ke REST API, Prisma client, dan authentication.

4. **Tahap paling penting berikutnya:**
   menghubungkan modul ke database dan API nyata, bukan menambah fitur baru.
